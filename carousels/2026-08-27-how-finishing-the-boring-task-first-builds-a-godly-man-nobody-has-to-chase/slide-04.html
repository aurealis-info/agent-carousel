Step 3

Finish it completely, not mostly

Ninety percent done still means someone else has to remember the last ten percent. A man who's actually useful closes the loop himself, every time, even when no one's tracking it.

  • Finish the boring task all the way.
  • Then tell someone it's done, don't wait to be asked.

Half-finished work still needs a babysitter.
